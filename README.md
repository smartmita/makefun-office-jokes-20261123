Minimal deterministic Node 22 entrypoint emitting a single-line office joke under 200 characters to `/output/entry.txt` for make.fun's "Make the AI Judge Laugh: Office Jokes" bounty.

## Validation

The script validates UTF-8 single-line formatting and the 1–199 character gate before writing `entry.txt` into `MAKEFUN_OUTPUT_DIR` (default `/output`).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
